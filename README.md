# Yagi EV Solar Charging Selector

A customer-facing planning tool from Yagi GreenVision for sizing affordable EV solar charging systems in Ethiopia.

## What customers can compare

- EV presets or a custom battery and consumption
- Daily driving energy
- Existing or proposed PV size
- Available EEU grid support
- Solar charging time and grid supplementation
- Entry, balanced, and faster package options
- Inverter and zero-export configuration guidance

## Live selector

https://girjamesmira-beep.github.io/yagi-ev-solar-selector-live/

## Important

Results are planning estimates based on the assumptions shown in the selector. A Yagi GreenVision site assessment is required before procurement or installation.
